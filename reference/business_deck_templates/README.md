- 解説・部品表・作成手順: `docs/business_deck_templates.md`
- `by_industry/{業種}/NN_用途.html` が原本(取り込み日 2026-10-07)。**直接編集せず、コピーして使う**
- 業種フォルダ: 標準 / SaaS / 製造 / 人材 / 医療介護 / 飲食小売 / 不動産建設 / 物流運輸 / 士業コンサル
- 取り込みはHTML全文を保存しただけで、加工していない
