# POS(nightwork-pos)への反映 引き継ぎメモ

2026-09-28 時点。POS 本体 `pokkiriofficial/nightwork-pos` に、このセッションからアクセスできなかったため、
POS 側でやることをここに残す。質問の正は `spec/items.yaml`。下の一覧はその写し(変わったら作り直す)。

## 回答が POS に届くまでの流れ

1. 店舗が導入アンケート(https://pokkiri-night-survey.vercel.app)に答える
2. 最後のページで「文章をコピー」を押し、LINE で担当者に送る
3. 担当者が運営コンソールで、その文章を貼り付けて取り込む
4. 取り込んだ内容が、その店舗の設定画面に反映される

外部から叩ける送信経路(API・共有シークレット)は作らない。貼り付けでの取り込みに一本化する
(2026-09-26 のセキュリティ方針。コミット 46b35cb)。

## POS 側でやること

- [ ] 貼り付け画面が落ちることがある。原因を再現してから直し、落ちないようにする(最優先)
- [ ] 取り込み(`onboarding-survey/import.ts` と聞いている)を、下の質問名・答え方に合わせる
      (2026-09-28 に質問名と構成を大きく変えた)
- [ ] 取り込んだ内容を、店舗の設定画面に反映する
- [ ] 店舗の設定画面の見た目: アンケートにある項目は、アンケートと同じ章・質問名・答え方
      (選択肢・表・「有無」を先に聞く出し分け)にそろえる。アンケートにない項目は今の画面のまま
- [ ] 店舗の設定に、次の設定を追加する(2026-09-30)
      - 個室料: 卓ごとの金額。アンケートでは「個室料の有無」が「あり」のときだけ、「卓の一覧」に「個室料(円)」の列を出す(空欄可)。
        その卓の会計に1回付く。ハウスチャージとは別。
        卓の名前などを変更する画面(卓の編集)で変更でき、フロア画面(iPad)からも設定できるようにする
      - ボトルキープの期限(ボトルキープなし/期限なし/1か月〜1年。最後の来店日から数える)。フロア画面には出さない
      - ボトルキープの期限のお知らせ(お知らせしない/3日前/7日前/14日前/30日前)。
        期限が近いボトルを、管理画面の顧客管理でお知らせ(アラート)する
- [ ] 店舗の設定に「領収書の通し番号の有無」(なし/あり)を追加する(2026-10-02)
      「あり」のとき、領収書に1枚ごとに増える番号(例 No.000123)を刷る
- [ ] アンケートの最後のページで「あとから管理画面・フロア画面(iPad)の設定で変更できます」と案内している。
      領収書の種類以外のすべての項目が、設定で変えられるか確かめる

## 名簿・キャスト別バックについて(2026-10-07 追加)

名簿(テーマ5)とキャスト別バック(テーマ7)は、貼り付け取り込みの対象外。導入担当が POS の画面に入れる。

- [ ] **POSに列を作る(2026-10-07 作成を承認済み):** 読み仮名(キャスト・スタッフ)、入店日(キャスト・スタッフ)。
      cast_profiles・staff_profiles に列を足し、基本情報カードに入力欄を出す。migration を作るのは沢田さん。
      本番DBへの適用が先、コードはあと(POSのCLAUDE.md 6・8)。それまでは、担当者のメモとして扱う
- [ ] **区分の対応:** 在籍=status:active、体験入店=status:trial、派遣=isDispatch、日払い=isDailyWage。
      体験入店と派遣は、POSでも同時に選べない
- [ ] **キャスト別バック:** メンバー台帳の「バック(個人ごと)」に入れる(店舗がやる)。対象は
      セット・延長・指名・担当卓の売上・ドリンク・ボトル・フードの7種類。個人ごとに切り替えると、
      同じ種類の店舗共通ルールは止まる。①で「キャストごとに違う」と答えた種類だけが対象

## 回答の文章の書式

```
【ポッキリ.Night初期セットアップフォーム】
回答日:2026年9月28日(月)
訪問日:10月5日(月)        ← URL に ?visit= があるときだけ

■店舗名
クラブ〇〇

■料金セット
セット1/60/8000、VIPセット/60/15000
```

- 1問ごとに、空行・「■質問名」・答え の順に並ぶ。出ていない質問(条件に合わない質問)と説明だけの欄は書かれない
- 選択肢は、その文字のまま。複数選べる質問は「、」でつなぐ
- 「未定」は、まだ決まっていないという答え
- 「その他」「あり」「記入」に書き添えた値は、後ろに「(値 単位)」で付く。例:`あり(10%)`
- 選んだ選択肢の横に入力した値も、同じ形で付く。例:サービス料 `率で指定(20%)`・`金額で指定(1000円)`
- 数字の質問で単位があるものは「値 単位」。例:`50000 円`
- 金額・率は「値単位」。例:`50%` `1000円`
- 時刻は `HH:MM`
- ダイヤル(`dial`)で選ぶ質問は、選んだ文字のまま。例:遅刻控除の時間の区切り `15分`
- 表は、1行を「/」でつなぎ、行どうしを「、」でつなぐ。空のマスは `-`
- 表の列のうち、条件に合わず出していない列は、文章にも入らない(例:個室料の有無が「なし」なら、卓の一覧は「卓名/席数」だけ)
